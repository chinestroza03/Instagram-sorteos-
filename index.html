¿Cómo copio los comentarios?
  1. Abre la publicación en instagram.com desde el computador.
  2. Pulsa el botón “+” / “Cargar más comentarios” hasta que se vean todos.
  3. Selecciona todo el bloque de comentarios (o usa Ctrl+A) y cópialo con Ctrl+C.
  4. Pégalo abajo. La app reconoce el usuario de cada comentario e ignora textos como “Responder”, “3 sem” o “12 Me gusta”.

¿Tienes una lista simple? Elige “Lista de usuarios” y pega un usuario por línea.

Acepta .csv, .json o .txt. Sirve para exportaciones de herramientas de comentarios o la respuesta JSON de la API. Se detectan columnas como username, usuario, autor y text, comentario.

¿Qué necesito para usar la API?
  • Una cuenta de Instagram profesional (empresa o creador).
  • Un token de acceso con permisos para leer comentarios: de la API de Instagram con inicio de sesión de Instagram (empieza por IG…) o de la Graph API de Facebook (instagram_basic, instagram_manage_comments, pages_show_list).
  • Puedes generar uno en el Explorador de la Graph API.
  • El token sólo se usa en esta pestaña para consultar a Meta y no se guarda en ningún lado.
